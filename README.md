# Understanding People

**Public site:** <https://parsedw.ink/un-pe/>

A personality assessment web app based on Dave Mitchell's book
[The Power of Understanding People](http://www.amazon.com/Power-Understanding-People-Strengthening-Organizational-ebook/dp/B00E1JO4Z8).

The user ranks their preferences across 12 sets of 4 statements; the results
determine their personality style, shown with a description and quick-reference
guides. Progress is saved in the browser and the app installs as a PWA.

## Quick start

```sh
brew install node bun
bun install
bun dev
```

See [AGENTS.md](AGENTS.md) for architecture, conventions, testing, and the full
command reference.
